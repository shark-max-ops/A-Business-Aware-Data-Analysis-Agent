# 分析使用说明 v4（阶段 4）

来源类型：project_policy。用途：说明本项目已实现的操作与功能边界，不是 BTS 官方手册。更新日期：2026-10-31；本文件更新会导入新修订，旧准备稿仍保留在历史中。

## 启动与导入

从根 README 完成 `uv sync --locked` 和 `uv run alembic upgrade head`，再启动后端与前端。知识管理入口为 `/knowledge`，API 说明位于后端 `/docs`。
已有准备文件时，从根目录执行 `uv run python -m metric_pilot.knowledge.seed`，核对哈希后导入七份材料、绑定真实文档修订，并保存八个指标草稿。重复执行不会覆盖已经编辑的指标，也不会自动审核。
官方原件在 `data/knowledge_sources/`，UTF-8 摘录与转换代码表在 `data/knowledge_prepared/`，项目说明在 `knowledge_seed/project/`；manifest 是可移植的来源清单，不是服务端知识快照或正式修订。

## 原始文档

在“原始文档”选择 UTF-8 Markdown/TXT（最大 500 KB），填写标题、来源类型、网址及已知生效期。官方资料必须给出 http(s) 出处；未知日期留空。页面不直接解析 PDF 或 HTML，应先整理为保留来源定位的 Markdown。
新建保存 v1；更新须选择已有文档，保存新版本。系统先保存原文再排队分块/索引，页面显示实际任务状态，失败可在处理任务中重试。
“原文与历史”可查看旧版原文、哈希和片段的字符/行坐标。官方材料中的项目阅读提示单独标为项目整理，不能把中文提示作为官方原文引用。

## 检索与知识快照

输入中文或英文问题，选数据适用日期。首次检索固定知识快照；后续编辑不会改变这个范围，需要“更新知识快照”才能查阅新版本。当前已审核指标和已发布 Wiki 的来源旧修订也随快照固定。
关键词检索无需模型；中文问题通过维护的中英别名和中文索引找到英文原文。返回实际片段，并附来源类型、固定修订和定位。
“构建/更新向量索引”显式调用本机配置的 embedding 服务；之后可选“关键词 + 向量”。模型/端点/维度改变不混用旧向量；缺索引会报错，不冒充混合检索。原文片段做混合检索，已发布 Wiki 另作关键词导航。
未知历史生效期会显示限制；有明确适用期且日期不匹配的资料不参与该日期检索。

## Wiki 草稿、发布与回滚

可以选择输入文档、填写页面标识，显式调用文本模型生成带引用的草稿；没有模型也能人工建立草稿。从原文或检索结果选择引用，再插入正文，保留每个事实段落的 `[chunk_…]` 标记。
输出必须通过输入范围、片段存在、摘录包含、哈希及段落引用校验。引用错误最多反馈重写一次，仍不合格则任务失败，不自动放宽标准；引用真实不代表解释必然正确。
人工保存创建新草稿版本；生成期间的旧基线遇到新人工编辑会冲突，不能覆盖它。编辑框保留载入时的版本，冲突后先查看或载入最新正文。
核对引用与已发布内容的差异后，“审核并发布”只发布已保存的服务器版本；未保存的编辑不会发布。已发布内容进入之后创建的知识快照。
历史回滚创建新草稿，不删除旧版本，也不自动改变已发布版本。一个工作区最多 40 个 Wiki 页面，首版使用平面目录。

## 指标审核

表单明确名称、单位、分子、分母、分组、过滤、所需字段、空值规则、生效期及来源文档修订。保存始终是草稿；“审核此指标”才创建已审核修订，不会修改旧草稿。
八项首批规则均是项目口径。首版不支持把自由编辑的公式直接批准为官方指标，也不执行公式字符串或把它当作可执行代码。
更新知识快照后，可按日期检查指标是否适用。未审核、日期不符、固定候选有冲突时不猜测规则。批准指针代表该指标在新快照中的活动版本；旧快照仍指向原修订。
本机八个初始指标仍待用户业务审核。测试中对合成指标的审核不代表正式项目规则已批准。

## 自然语言分析

在 `/analysis` 选择已登记的数据快照并输入问题。模型通过原生工具调用查资料、解析指标、看表结构和执行安全 SQL；问题下方显示实际执行摘要，点击可展开步骤；“执行详情”按需打开 SQL、参数、来源与错误。当前 Agent 明确使用关键词检索，知识管理页仍可使用混合检索。
开始时固定数据、知识和预算，运行中资料更新不改变依据。指标必须已审核且适用于整月；八项实际项目指标仍待人工审核，Agent 没有审核或发布权限。缺规则、字段或条件时显示澄清，用户补充后创建新运行。
分析完成后可打开中文报告，查看关键数字、表格、柱状图或折线图。结构化数字与文字占位符由服务端从本次成功冻结产物取值，不把资料片段或失败查询当作数字依据。自由 SQL 的执行与引用检查不自动证明业务语义。
刷新、切换页面或断网不会自动取消，重连按事件序号恢复。“停止分析”才会取消实际模型请求和查询进程。服务重启把正在运行的任务标为中断；重新发起会创建新运行，不冒称恢复模型内部状态。
模型默认最多 16 轮、24 次工具调用、180 秒；错误修正和传输重试均有上限。只展示简短行动与工具反馈，不保存内部思维正文。

## 报告、取证与历史版本

在分析结果中点击“打开完整报告”，或从“报告”页选择已保存报告。点击关键数字、表格单元格或图表数据点，可查看原始值、统计范围、SQL、绑定参数、数据哈希、已审核口径及固定原文。技术信息默认折叠，正文以中文阅读为主。
报告只引用本次运行的成功查询；跨运行、缺失列、越界行、截断结果和不支持的图表配置会被拒绝。百分比来自 0—100 的 *_pct 列，显示不再乘百；null 显示“无可用值”，不当作零。
报告固定保存生成时的数据和来源副本。切换数据、更新原文、修改或回退口径，不会替换旧报告的数字和依据。“修改说明”保存为新版本，旧版保留；并发修改会提示冲突。可以导出 Markdown 或 JSON，当前不提供 PDF。
资料或已审核指标不足时，分析会说明缺什么，不会为了生成报告编造结论。报告显示“数字与引用已核对”不代表所有业务解释已经自动验证，正式业务结论仍需复核。

## 当前边界

阶段 0—1 的数据导入、固定快照、SQL 防护和成功查询产物继续可用。阶段 2 已验证真实 embedding 与文本模型路径；健康检查只检查配置/本地状态，不发收费请求。
后台任务持久化，失败可重试；重启后正在执行的旧任务标为中断失败，不声称模型调用已恢复。真实模型可能产生费用；响应提供用量时记录数值，不记录内部思维正文，也不虚构费用。
阶段 3 已接入自然语言 Agent、工具和事件恢复；阶段 4 已接入可追溯报告、数字取值、历史版本与导出。当前没有实施整体问答准确率评估、模板口径自动证明或跨月推断。八项实际指标仍待用户审核，Wiki 生成内容仍须人工核对并显式发布。
