# 0007：数据探索与正式项目指标分开授权

日期：2026-11-02。用户试用到达偏差分布调查时，模型主动解析尚未审核的到达延误率与有效到达范围，旧逻辑因此封锁了整轮查询。仅改成澄清提示仍无法完成合理的原始字段调查，本决策替代该全局封锁取舍。

query_sql 保留兼容的 standard 默认用途，新增显式 exploratory 与 reviewed_metric。未声明用途的旧调用仍受原指标绑定约束；解析失败后仅删除指标 ID 不能继续。exploratory 必须声明人群/排除、计算/分母和缺失处理，禁止绑定指标修订；reviewed_metric 必须提交非空修订集合，并经原有固定知识快照、解析与整月适用期校验。某个指标失败不影响正确解析的另一个指标。

这些用途不扩大数据库权限：查询仍经过同一 AST、允许表/函数、受限只读连接、子进程超时与取消；服务端固定运行、快照及 ID，只有执行成功产生 QueryArtifact。探索声明作为不可信说明保存，不能更改权限，不能自动证明声明与 SQL 语义一致。

服务端将 query_purpose、exploration_scope 与不可用指标键保存到不可变产物。探索工具结果、报告预览、发现依据和报告依据显示中文身份。报告指标集合仍须严格匹配引用产物实际绑定集合，不能补填一个已审核 ID 为探索背书；服务端按产物强制追加探索限制，报告人工修订也沿用。未引用的已选指标不再显示为报告实际使用口径。旧产物读取兼容默认 legacy，旧报告文件及摘要不改。

首次未声明用途的查询被审核阻断时，返回明确可选路径，允许模型修正为有范围说明的独立探索；重复同一拒绝动作两次时正常澄清结束，补齐工具消息，不报普通重复故障。预算、取消与终态保存沿用原实现。真正缺少业务条件、收入成本或正式指标时仍应说明缺口；探索不代替用户明确要求的正式项目指标结果。

限制：任意自由 SQL 的业务语义和自然语言标题无法通过用途枚举自动证明。允许相同字段上的透明探索计算，不声称能阻止模型所有措辞误用；结构化身份、报告限制与实际 SQL 供用户复核。没有使用问题到 SQL 映射、特定问句路由或自动批准规则。阶段 5 外部来源未接入。

新增字段占用上下文，因此工具签名去除纯展示 title，保留必填、类型、枚举及长度等约束。固定最近查询摘要保留产物索引，并缓存不超过 1200 UTF-8 字节的小型真实结果，标出 complete；不把部分预览当完整统计。少量已查来源短摘录和定位随固定上下文保留，减少重复检索；与本轮问题完全相同的目标不重复全文。空间紧张时缩短来源摘录及预览，保留最新整批工具配对、范围及引用，仍放不下才失败。原始审计与产物不改，既定预算不扩容。

最新工具组优先于可选缓存副本。紧凑模式可把已成功执行的历史 SQL 参数转成明确标注、不可重放的定位摘要，冻结产物 ID、探索范围及工具配对继续保留；模型上下文中的摘要不用于任何执行，完整原 SQL 与调用仍保存在审计及产物中。同组 record_finding 返回的引用映射只有与输入完全相同时才合并一份，保留输入中的完整映射，不合并不一致引用。原问题和调查目标仍完整保留；旧发现仅带短线索，完整历史按需读取。最后真实失败点已做离线重放，但该上下文修改尚未完成新的真实整题验收，不能将其宣称为模型稳定性验证通过。

真实试用还暴露了可选分位数查询反复使用未开放 ROW_NUMBER 的问题。函数白名单不因此放宽；查询服务仅反馈函数名、允许列表与中文修正建议，不返回连接信息或原始异常。已有成功查询可以用于后续报告，失败查询仍无产物；模型应在报告说明做不了的可选统计，不原样重试。未引入任意代码或统计插件。
